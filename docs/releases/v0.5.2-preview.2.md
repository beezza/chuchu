fishをログインシェルにしているSSHホストで、インストール済みのtmuxが未検出になる不具合を修正しました。

### 修正内容

- SSH管理コマンドとtmux接続開始処理を、明示的にPOSIXシェルで実行します。従来はPOSIX構文をfishが直接解釈して失敗していました。
- fish / bash / zsh / shで引用符・バックスラッシュ・日本語・改行を保持するコマンド引用を追加しました。
- シェル構文エラー、SSH execの失敗、タイムアウトを「tmuxがない」と誤判定しないようにしました。
- 本当に見つからない場合は、SSHコマンド実行時のPATHで未検出だったことを表示します。

ターミナル入力処理やユーザーのfish設定は変更していません。

### インストール

- `chuchu-0.5.2-preview.2-arm64-v8a.apk`：Android 7.0以上、arm64-v8a端末向け。
- versionName: `0.5.2-preview.2` / versionCode: `501902`。
- preview.1および既存Nightlyと同じGitHub Actionsの署名鍵で作成します。APKを上書きインストールしてください。
- AABと`SHA256SUMS`も添付します。

### 検証

- 全171テスト中166件成功、既存5件スキップ、失敗0件。Debug APKビルドとlintも成功しています。
- 実際のfish / bash / zsh / shでSSHコマンド文字列を実行する回帰テストを追加しました。
- 隔離tmuxソケットでfish経由の検出・一覧・作成・名前変更・プレビュー・PTY接続・終了を検証しました。ユーザーの既存tmuxセッションは操作していません。
- 実機Androidからユーザーのホストへの接続は未確認です。

実装と制限は [tmux session manager](https://github.com/beezza/chuchu/blob/v0.5.2-preview.2/docs/tmux-session-manager.md) を参照してください。
